# A02 视频采集与平台适配器

日期：2026-11-04。实施前工作区干净，基线 fa700de。保留 A00/A01 全部证据，只完成 A02。

## 范围与设计

上传 MP4/MOV、分享文本解析、可替换 SourceAdapter、异步下载/基本媒体校验、持久化状态和最小导入页。无切镜、ASR/OCR、模型、脚本或 A07 工作台。默认端口 3100。

API 不运行媒体工具。原始二进制上传通过流式计数写入 UUID 独占目录；媒体 Worker 验证 ISO BMFF 签名、ffprobe 容器/视频轨、时长和完整解码。下载 Worker 无公网网卡，只能通过独立 CONNECT 网关访问白名单 HTTPS；网关逐连接解析全部 DNS 地址，拒绝任何非公网地址，直接连接已验证数字 IP 并复核 peer，避免二次解析。每次重定向新连接同样受检；客户端限制重定向数。TLS 校验由下载器保留。网关不挂数据卷/secret，不记录目标 URL。HTTP、任意 direct_media、非白名单 CDN 均 fail closed。

首批抖音优先，TikTok/B站/YouTube 使用同一固定版 yt-dlp 适配器，均为实验性、需授权、未获真实样例验收；禁止 Cookie/账号、DRM、验证码、地理绕过、远程插件/JS。只取可直接下载的单文件 HTTPS MP4，不降级到其他格式；HLS/DASH/音视频分离暂明确不支持并回退上传。平台新增 CDN 需审查白名单。

## 合同与迁移

Pydantic/OpenAPI 为来源。新增 POST /api/v1/assets/upload（raw bytes，Content-Length，X-Authorized:true）；POST /assets/resolve（text, authorized:true）；POST /assets/{source_id}/acquire；GET /acquisition/jobs/{job_id}。浏览器使用随机 HttpOnly same-site session，FastAPI 验证相同 owner 哈希，未知/越权统一 404；同源 Next 代理校验 Origin，不接受客户端 owner。API 仅可信本机或管理网络，不公开到互联网。

状态 PENDING→ACQUIRING（链接）→PROBING→SUCCEEDED / FAILED_PERMANENT；瞬时网络错误最多两次，attempts 持久化，队列发布失败明确终止，允许重新提交。阶段原子更新避免重复执行。任务超过总时限查询时终止为超时；临时目录由任务 finally 清理，硬终止残留以维护命令清理。A08 的完整取消/恢复不提前实现。

0002_acquisition 增加 source/job 表，保存 owner、规范化来源、平台资源 ID、adapter 版本、SHA256、字节数、验证摘要、状态/错误/时间；不保存分享文案、签名 CDN 或 Cookie。downgrade 先备份 DB 与 work_data，删除本卡表，文件保留；恢复通过备份成对还原并 upgrade。A01 readiness 升级 head，原健康响应兼容。

## 先列失败用例与验收

成功：合成 MP4/MOV 上传→真实队列→解码→哈希/文件持久化；文本解析/重复 acquire 幂等；浏览器状态与刷新；受控 adapter 下载路径集成（不是平台证据）。

失败/安全：空/损坏/假扩展名/假 MIME/无视频轨/超限/超时；userinfo、端口、相似域名、file/http、多个 URL、私网/IPv4-mapped/混合 DNS/metadata/rebinding/重定向；shell 字符和路径穿越；所有权、跨站提交、上游非法合同/超时/不可达、限流/403/404/登录；工具失败无正文泄露、失败清理、队列发布异常、有限重试、迁移往返与重启。

命令：backend uv run --frozen ruff check / mypy / pytest；frontend npm run verify；python scripts/verify_a01_e2e.py（独立 evidence/A02 子目录）；新增 A02 真实 Compose 验收。每条记录退出码和数量。真实授权平台样例未提供则 BLOCKED，继续上传/隔离验收。无 GPU 不阻塞 A02。Ubuntu 原生、真实平台成功和生产压力测试均不得由 mock/本机结果替代。
