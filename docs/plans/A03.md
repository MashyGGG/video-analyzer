# A03 实施计划与失败场景

日期：2026-11-14。范围为媒体元数据、物理镜头及可追溯帧，不实现 ASR/OCR、语义分段或模型推理。

## 设计

1. 在隔离 media worker 中处理 A02 已验证且属于当前用户的本地资源；原始文件只读，禁止网络媒体输入。记录版本、哈希、音轨、旋转、尺寸、时基和帧时间戳。
2. 使用固定版本 PySceneDetect 检测物理边界，映射到实际解码 PTS；镜头采用整数毫秒半开区间，VFR 不使用帧号除以名义帧率。时间戳无法可信映射时明确拒绝。
3. 逐镜抽取代表帧和缩略图，记录实际原始 PTS、时间及校验和；中间产物在专用临时目录生成，完整验证后原子发布。失败、重试及并发不得损坏现有结果。
4. 通过有所有权检查的任务及结果接口暴露状态和 JSON，维持 A02 合同；记录依赖许可、部署与复现命令。
5. 使用合成媒体验证正常、无声、竖屏、VFR、旋转、单镜、快速切镜、闪白及损坏流；单独保留真实人工标注集的 F1 门槛，未取得数据则标记 BLOCKED。

## 先行失败用例与验收

- 输入不属于用户、资源尚未采集成功、路径越界或符号链接：拒绝且不读写其他资源。
- 容器或轨道损坏、无视频轨、PTS 缺失/倒退/无法映射、资源超限：明确失败，不输出成功结果。
- ffprobe、解码、检测或抽帧超时、进程崩溃、空间不足：清除本次临时产物，保留已发布结果，并可安全重试。
- 代表帧的实际时间必须落在对应半开镜头内；镜头连续、单调、无重叠且覆盖有效视频时长。
- 重复提交、同时执行、worker 中断恢复与队列故障：状态和产物可恢复，不得产生伪成功、越权或重复输出。
- 依赖、Compose、迁移或健康接口变更后运行 `python scripts/verify_a01_e2e.py`；环境不可用时记录 BLOCKED。真实基础设施结果与 fixture 分开记录。
- 真实视频留出集的人工标注、F1 ≥ 0.85 和误差门槛无法由合成数据替代；缺少授权标注集时整体验收 BLOCKED。
