# ADR-002：接受轻量底座并启动 A01

日期：2026-11-04。状态：Accepted。来源：用户在明确说明“确认自建轻量底座后进入 A01”的上下文中指示“进入下一步”。

采用 [ADR-001](ADR-001-foundation.md) 的轻量底座方案；不复制 parse_video 业务代码、依赖、迁移、模型或素材。按既定技术栈实施 A01，不推进 A02–A09。此前用户已授权仓库 commit/push，后续本任务验证完成后提交至同一 main。

A00 文档和 evidence/A00 保留当时的历史状态与哈希，不补签未执行的测试。原始启动/测试的明确阻塞是 A00 允许的结果；真实 GPU、真实模型和离线全链路分别归入 A05/A09，不作为 A00 或 A01 基础服务的通过条件。上游未解析的传递依赖和动态出站缺口仍存在；由于不继承它们，不据此声称上游依赖已经获准。A01 对新选依赖另行锁定和登记。

A01 GPU 配置只提供可选择的硬件诊断，不在本阶段引入未验证的推理镜像/权重。AMD 开发机可以完成 CPU 基础设施测试；Ubuntu 正式部署和 NVIDIA 检测执行情况分开记录。
